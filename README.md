# CHANDPUR VIBES — GitHub Pages website

## Publish on GitHub Pages
1. Create a new public GitHub repository, e.g. `chandpur-vibes`.
2. Upload `index.html` and the entire `assets` folder (preserve filenames).
3. Open repository Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. After deployment, GitHub provides a URL such as `https://YOUR_USERNAME.github.io/chandpur-vibes/`.

## Notes
- Form uses WhatsApp click-to-chat. Customer must press Send; there is no backend storing leads.
- Weather uses the free Open-Meteo geocoding and forecast APIs. Internet required. If Chandpur cannot be matched to Bijnor, a fallback status is shown.
- The animated 5,452,364 counter is explicitly marked as demo, not a real analytics counter.
- Hero slides use provided brand poster/logo and a gradient rather than unverified third-party location photographs.
- All website assets are included locally; no broken external image links are required.
- Footer button destination: https://allnuttons.blogspot.com/
